WarHeads Classic Enhanced SPRITES Folder

Put exported sprite packs and individual sprite JSON files here.

How sprite packs work:
- Sprite packs are graphics-only.
- They do not change damage, physics, weapons, turns, credits, or multiplayer rules.
- Use the in-game SPRITE EDITOR to edit a sprite item, save it to your local sprite pack, then export one sprite or selected sprites as a pack.
- You can restore a single item to default or reset all local sprite overrides.
- Future multiplayer builds can allow rooms to prefer the server sprite pack while players may still choose their own local graphics.

Recommended names:
- WarHeads-SPRITE-shot-shell.json
- WarHeads-SPRITES-my-pack.json
