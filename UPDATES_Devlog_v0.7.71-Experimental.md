WarHeads Classic Enhanced v0.7.71 Experimental Branch

Summary
- Starts a dedicated Experimental Branch from v0.7.70.
- Applies the first in-game UIX modernization pass only.
- Leaves the main menu / pre-game flow untouched.
- Adds the first playable Credits economy pass.

Included in this build
- New in-game HUD inspired by the chosen mobile-game mockup.
- Top profile card, central timer card, player roster card, modern bottom control dock, and large FIRE button.
- Credit display in the HUD.
- Weapon cost preview in the in-game weapon panel.
- Credits are deducted when the local human player fires.
- Credits are rewarded for damage and eliminations from that fired shot.
- Historical note superseded in later builds: credits are session-only per match/server, not persistent browser storage.

Notes
- This is a first presentation + economy scaffold pass.
- Pre-game menus were intentionally left as-is.
- In-game chat button currently shows a planned-feature notice; full chat slideout is intended for the next experimental UI update.
