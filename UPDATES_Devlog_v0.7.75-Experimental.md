# WarHeads Classic Enhanced v0.7.75 Experimental

Experimental Branch pass focused on the final visual merge and the first extended elemental / alien weapon push.

## Visual Merge
- Brought the main menu, editors, options panels, and mod screens toward the same premium mobile-game / browser-game UIX look as the new in-game HUD.
- Kept the current in-game HUD look unchanged.
- Kept the working mobile menu flow intact.
- This pass is visual-only for menu styling: same buttons, same flow, better look.

## Economy Pricing
- Alien and extended elemental stages now price as premium weapons.
- Weapons using those stage types default to the expensive 25,000-100,000 credit band.
- Normal/basic weapons still use the lower economy defaults.
