WarHeads Classic Enhanced MUSIC folder

The game includes 12 generated soft chiptune tracks by default.

To add your own hosted music, place audio files here and list them in playlist.json.
Example playlist.json:
[
  "my-song.ogg",
  "my-other-song.mp3"
]

Browser security note:
Custom music works best when the game is served from a local or web server.
Some browsers block local file playback when opening the HTML directly from disk.


v0.7.10 Advanced Options: custom hosted music can be listed in MUSIC/playlist.json and selected in Options.
